# Caption Flow

Este projeto é uma ferramenta aplicada à educação, focada em transformar o conteúdo audiovisual do YouTube em um script de ensaio. Diferente de simples legendas, o Caption Flow organiza a transcrição como um roteiro teatral, sincronizando o progresso do vídeo com o texto para que o estudante possa estudar a estrutura, o vocabulário e a entrega de cada fala.

- [ ] Extração de transcrições de vídeos do YouTube
